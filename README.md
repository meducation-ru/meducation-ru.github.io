# Карманный набор ЛОР-врача

Опросники, шкалы и схемы для оториноларинголога. evidENT 2026, Форум доказательной оториноларингологии, Meducation.

Статический сайт без сервера: всё считается в браузере, ответы никуда не отправляются. После первого открытия работает без интернета.

Набор только для врача. Калькуляторы и памятки справочные, по опубликованным методикам: решение о диагнозе и лечении принимает врач по результатам осмотра.

Иллюстрации уха по Саде и Тосу построены на модели OpenEar (препарат ZETA): Sieber D. et al. Sci Data 2019, doi 10.1038/sdata.2018.297; данные Zenodo, doi 10.5281/zenodo.1473724; лицензия CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Изменения: перепонка перестроена под стадии, стенки слухового прохода построены заново, в кадрах Саде косточки повёрнуты.

Опросники принадлежат их правообладателям; авторство указано на экране каждого инструмента.
